Bronze schema data dictionary

Notebook 07 recreates the bronze schema tables from the local MEVA-style exports. It removes the earlier public tables first, then replaces all Bronze data on every run.

event_objects is the only relationship between events and objects: an event can involve multiple objects, and an object can participate in multiple events. A geometry belongs to an object. There is intentionally no direct foreign-key relationship between videos and objects.

bronze.videos

Column Type Nullable Description
video_id TEXT PK no Stable SHA-256 ID derived from the video name.
video_name TEXT unique no Source MEVA video name.
camera_id TEXT yes Camera identifier embedded in the source name, such as G340.
scene TEXT yes Scene label embedded in the source name, such as bus or school.
capture_start_local TIMESTAMP yes Capture interval start parsed from the source name.
capture_end_local TIMESTAMP yes Capture interval end parsed from the source name.
capture_time_zone TEXT yes Capture time-zone status; currently unknown.
duration_seconds DOUBLE PRECISION yes Original video duration.
frame_count INTEGER yes Number of source frames.
fps DOUBLE PRECISION yes Original video frames per second.
frame_width INTEGER yes Source-frame width in pixels.
frame_height INTEGER yes Source-frame height in pixels.
source_video_path TEXT yes Original local AVI path at export time.
storage_bucket TEXT yes Cloudflare R2 bucket containing the MP4.
storage_path TEXT unique yes Object key in the R2 bucket.
video_url TEXT yes Public Cloudflare R2 URL for the MP4.
source_metadata JSONB no Original metadata-export object for traceability.
created_at TIMESTAMPTZ no Row insert time; defaults to NOW().
updated_at TIMESTAMPTZ no Row update time; defaults to NOW().

bronze.events

Column Type Nullable Description
event_id TEXT PK no Stable SHA-256 ID, unique across all videos/cameras.
video_id TEXT FK → bronze.videos.video_id no Parent video.
event_name TEXT yes Model-generated event label.
description TEXT yes Model-generated event description.
start_frame INTEGER yes Inclusive source-frame start for the selected window.
end_frame INTEGER yes Inclusive source-frame end for the selected window.
start_seconds DOUBLE PRECISION yes Window start timestamp in the original video.
end_seconds DOUBLE PRECISION yes Window end timestamp in the original video.
source_status TEXT no Annotation provenance, currently generated.

bronze.objects

Column Type Nullable Description
object_id TEXT PK no Globally unique SHA-256 ID derived from the source video ID and local tracker ID.
source_object_id TEXT no Local YOLO tracker ID from the source export.
detection_count INTEGER no Number of retained frame detections.
first_seen_seconds DOUBLE PRECISION yes First observation time in the video.
last_seen_seconds DOUBLE PRECISION yes Last observation time in the video.
label_details JSONB no Per-label descriptions, confidence summary, detection count, and spatial positions.

source_object_id is the local YOLO tracker ID and is not globally unique. The relationship to a video is represented only when the object is connected to an event through bronze.event_objects, then to that event's bronze.events.video_id.

bronze.event_objects

Column Type Nullable Description
event_id TEXT PK/FK → bronze.events.event_id no Referenced event.
object_id TEXT PK/FK → bronze.objects.object_id no Referenced participating object.

The combined primary key (event_id, object_id) prevents the same object from being linked to the same event more than once.

bronze.geometries

Column Type Nullable Description
geometry_id TEXT PK no Globally unique SHA-256 geometry ID.
object_id TEXT FK → bronze.objects.object_id no Parent tracked object.
source_geometry_id INTEGER no Original per-video geometry record ID.
frame_index INTEGER no Original-video frame index.
timestamp_seconds DOUBLE PRECISION no Time in the original video.
label TEXT yes YOLO detector label for this frame.
confidence DOUBLE PRECISION yes YOLO detection confidence for this frame.
spatial_position TEXT yes Coarse position, such as top-left.
bounding_box_pixels JSONB no Bounding rectangle: x_min, y_min, x_max, and y_max in original-frame pixels.

The (object_id, source_geometry_id) pair is unique. Geometry labels can vary for a single tracked object because they preserve the per-frame detector result.
